How to Add or Edit Calendars

This calendar viewer pulls data from public Google Calendars. To add a new class calendar or modify existing ones, you'll need to edit the js/config.js file.

Step 1: Get the Calendar ID

  1. Go to Google Calendar
  2. Find your calendar in the left sidebar
  3. Click the three dots (⋮) next to the calendar name
  4. Select "Settings and sharing"
  5. Scroll down to "Integrate calendar"
  6. Copy the Calendar ID (it ends in @group.calendar.google.com)

Step 2: Make Sure Calendar is Public

  1. In the same settings page, scroll to "Access permissions for events"
  2. Check "Make available to public"
  3. Choose "See all event details"

Step 3: Add to config.js

Open js/config.js and add a new entry to the CALENDARS array:

{
  id: 'unique-id',           // A short identifier (no spaces)
  name: 'Display Name',      // What shows in the filter buttons
  calendarId: 'abc123...@group.calendar.google.com',
  colorClass: 'cal-1170-primary'  // See color options below
}

Available Color Classes

Choose from these predefined color families:

  • Purples (1170): cal-1170-primary, cal-1170-secondary
  • Greens (1181): cal-1181-primary, cal-1181-secondary, cal-1181-tertiary
  • Blues (1190): cal-1190-primary, cal-1190-secondary
  • Reds (2740): cal-2740-primary, cal-2740-secondary

Adding New Color Families

To add colors for a new course (e.g., ENGL 2000), edit css/variables.css:

  1. Find the [data-theme="light"] section
  2. Add new color variables following the existing pattern
  3. Repeat for the [data-theme="dark"] section
  4. Add the color class definitions at the bottom of the file
/* In [data-theme="light"] */
--cal-2000-primary-border: #YOUR_COLOR;
--cal-2000-primary-bg: #LIGHT_BG;
--cal-2000-primary-text: #TEXT_COLOR;

/* Then add the class */
.cal-2000-primary {
  border-left-color: var(--cal-2000-primary-border);
  background-color: var(--cal-2000-primary-bg);
  color: var(--cal-2000-primary-text);
}

Step 4: Deploy Changes

  1. Save your changes to the config file
  2. Commit and push to GitHub
  3. Wait a minute for GitHub Pages to update
  4. Refresh this page

Troubleshooting

  • Calendar not loading: Make sure it's set to public in Google Calendar settings
  • No events showing: Check that the calendar ID is correct (copy it again)
  • API errors: The API key may need to be regenerated if it expires

Use the Helper Tool

For an easier way to generate the config code, use the standalone Calendar Config Helper tool (calendar-helper.html) which you can run locally on your computer.
