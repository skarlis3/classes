FYW Skeleton Proposal — ENGL 1181 (Track A)

This site is a working draft of a standardized skeleton for first-year writing classes at Macomb. The full proposal is for all FYW classes; the assignments, readings, and schedules gathered here are the ENGL 1181 Track A (Genre Analysis) version I've been building out as the first model.

Use the side navigation to read through the draft materials. Start with the Skeleton Draft for an overview. Then read through the assignment pages for more information on specific assignments. Eventually, I want to include more than one set of assignments as options.

The Proposal

Each FYW class gets a skeleton of core assignments and core readings.

Who uses it

  • Required for instructors (adjunct and PT) for all class modes.
  • Present as options for full-time faculty (who can either use them, not use them, or remix them).

Instructor choice built in

  • Will have more than one set of assignments to choose from.
  • Smaller scaffolding assignments are provided as support, but can be modified or replaced at instructor discretion.
  • Eventually may create a form for getting approval for replacement assignments that still fit the outcomes and objectives.
  • The 8-week online master shell will eventually have things like discussion boards and/or hypothes.is (social annotation) assignments added; for now I'm just working on the central skeleton.

Rationale

  • To ensure that outcomes and objectives are being met for the class.
  • To have one central source of truth for the classes (instead of multiple master shells).
  • Can be used as the base for online shells.
  • Will give instructors a starting place for non-online classes or class lengths where there isn't a master shell.

About This Draft (ENGL 1181 Track A)

Track A is a genre analysis approach. The skeleton uses a CORE / FLEX system:

  • CORE — required assignments and readings. Cannot be changed without departmental approval.
  • FLEX — scaffolding and recommended content. Can be altered, replaced, or supplemented freely, as long as the core projects and objectives remain supported.

Still Open
