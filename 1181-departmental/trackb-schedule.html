Example 16-Week Schedule — Track B: Digital Rhetoric & Social Media

Example schedule shown for a T/Th class. This is a suggested pacing guide — instructors should adapt it to fit their section.

Three writing projects, each graded when due, with an optional revision available after each. The final reflection is required at the end of the semester. Adapted from an 8-week online section; the extra weeks go into drafting and revision, not new content.

Numbered readings are chapters in the departmental OER textbook. Readings named by role — "the data reading," "the reflection reading" — are chosen by the instructor; see the Readings page for what each slot needs.

Week 1 — FLEX

  • Introduce the course, expectations, syllabus, and the course question
  • Introductions activity — FLEX
  • Since students may still be adding/dropping this week, this week is designed to be flexible.

Week 2: Critical Reading & Annotation

  • Readings: the argument readings (students choose one) and the data reading — CORE
  • Reading: 2.2 How to Read Effectively — CORE (satisfies the Chapter 2 requirement)
  • WA1: Reading Annotation — FLEX

The option a student chooses this week follows them into Projects 1 and 3.

Week 3: Entering the Conversation

  • Reading: 3.5 Academic Writing as a Genre — CORE
  • Reading: 7.1 Understanding Generative AI, plus one more from Chapter 7 — CORE
  • Introduce Project 1
  • WA2: Your Online Habits — FLEX

The GenAI reading lands here because Project 1 is the first assignment carrying a GenAI policy.

Week 4: Personal Experience in Academic Writing

  • Reading: 10.4 Weaving Personal Experience into Academic Writing — CORE
  • Reading: one of 4.1–4.3, the writing process — CORE (satisfies the Chapter 4 requirement)
  • Discuss using sources, signal phrases, and avoiding dropped quotes
  • Begin drafting

Week 5: Rough Draft & Peer Reading

  • Reading: 4.4 In-Class Peer Review — FLEX
  • Project 1 rough draft — CORE
  • Peer reading (YEPs / NOPEs / WOWs) — CORE

Week 6: Revision & Project 1 Due

  • Project 1 final draft — CORE
  • WA3: Process Freewrite — FLEX

Week 7: Rhetoric & Digital Identity

  • Readings: the digital identity readings — CORE
  • Reading: 3.1 What is Rhetoric? — CORE
  • Reading: 3.2 What is the Rhetorical Situation? — CORE
  • Reading: 5.1 Knowing Your Audience — FLEX
  • Introduce Project 2
  • WA4: Rhetorical Investigation — FLEX

3.1 replaces 3.3 Navigating Genres from the Track A core — this track is rhetoric-focused rather than genre-focused. 5.1 is the reading behind the audience choice students have been making since Project 1.

Week 8: Digital Rhetoric & Multimodal Analysis

  • Reading: 6.1 What are Multimodal Texts? — CORE
  • Reading: 6.2 Understanding Visual Rhetoric — CORE
  • Reading: 6.3 Visual Rhetoric and Digital Writing — CORE
  • WA5: Social Media Scrolling Log — FLEX

6.2 is substantially longer than 6.1, so it may want to start in Week 7 or split across both weeks.

Week 9: Rough Draft & Peer Reading

  • Project 2 rough draft — CORE
  • Peer reading — CORE

Week 10: Project 2 Due

  • Project 2 final draft — CORE
  • Optional revision of Project 1 available

Week 11: Choosing a Topic Strand

  • Readings: the topic strand readings — students choose a strand — CORE
  • Introduce Project 3
  • WA6: Reading Annotation, YEPS / NOPES / WOWS — FLEX

Week 12: Argument, Thesis & Outlining

  • Reading: 3.6 Understanding Essays — CORE
  • Reading: 8.4 Revision Strategy: Reverse Outline — FLEX
  • WA7: Argument Outline — FLEX
  • Discuss thesis statements, counterargument, and organizing an argument

Week 13: Rough Draft & Peer Reading

  • Reading: 8.1 Peer Feedback, Revising, and Editing — FLEX
  • Project 3 rough draft — CORE
  • Peer reading — CORE

Week 14: Revising & Self-Assessment

  • Reading: 4.5 Revising & Orders of Concern — CORE
  • Readings: 8.6 Editing and Proofreading; 12.2 MLA Formatting: The Basics — FLEX
  • WA8: Self-Assessment — FLEX
  • Project 3 final draft — CORE
  • Optional revision of Project 2 available

Week 15: Reflection

  • Reading: the reflection reading — CORE
  • WA9: On Reflection — FLEX
  • Optional revision of Project 3 available

Week 16: Final Week

  • Final Reflection due — CORE
